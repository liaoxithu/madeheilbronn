# MADE Together — MADE Heilbronn

Project introduction for the MADEHeilbronn manufacturing data initiative.

Public website: https://liaoxithu.github.io/madeheilbronn/

## Website files

- `index.html` contains the complete, editable project page, including its five team profiles and book references.
- `_next/static/` contains the compiled stylesheet. No JavaScript or server is required.
- `people/` contains the supplied portrait photographs. CSS framing preserves the original images.
- `.nojekyll` allows GitHub Pages to serve the static assets, including the `_next` folder.

Only website content and assets are included. Research data, contracts, transcripts, authentication configuration, and private-site history are not part of this repository.

## Publishing and updates

GitHub Pages publishes the root folder of the `main` branch. Changes pushed to `main` trigger publishing automatically.

For content changes, edit `index.html`. For appearance changes, edit the stylesheet linked in its `<head>`. Portrait framing is set on the image elements inside the People section.

To preview locally, serve this folder with any static HTTP server. Check both desktop and mobile layouts before publishing changes.

The public website retains the approved draft content, including two `XXX` citation placeholders. The separately hosted private review website is unaffected by edits to this repository.
